# Manuscripts

The revised manuscripts are paired as `rank2.tex` / `rank2.pdf` through
`rank6.tex` / `rank6.pdf` when each version is finalized. Rank three is an
unrestricted sphericality argument; ranks four to six use the pinned
fixed-rank census and explicit criteria for categorification.

| Manuscript | TeX | PDF | Scope |
|---|---|---|---|
| Rank two | [Source](rank2.tex) | [Read](rank2.pdf) | Complex fusion categories, unrestricted multiplicity |
| Rank three | [Source](rank3.tex) | [Read](rank3.pdf) | Unrestricted rank-three sphericality |
| Rank four | [Source](rank4.tex) | [Read](rank4.pdf) | Through multiplicity 128 |
| Rank five | [Source](rank5.tex) | [Read](rank5.pdf) | Classification through 17, frontier at 18 |
| Rank six | [Source](rank6.tex) | [Read](rank6.pdf) | Complete through 2, partial through 7 |

The TeX files may rely on nearby source sections or generated tables. In that
case, the full source tree is included under the corresponding `rankN/`
directory. PDF versions provide a stable reading copy. Counts and status
partitions in the repository root are [versioned separately](../docs/PROVENANCE.md).

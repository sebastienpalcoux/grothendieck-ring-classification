# Integer multiplicities in the oriented semion phase cone

This optional follow-up is separate from the accepted rational-cone replay.
It changes none of the frozen matrices or receipts in the parent directory.

The phase variables in the oriented R928 cone admit an integer refinement.
Each orbit of the central semion G contains exactly one positive-charge object
Z, because G has charge−1. Associate to this orbit the six normalized relative
traces of its twist to L=Q(zeta24). Averaging an STS or indicator equation over
the Galois group fixing L sends this single orbit's contribution to its trace
atom with coefficient1. Therefore the coefficient of an atom counts actual
G-orbits and is a nonnegative integer. The fact that a normalized trace may
itself be fractional in field coordinates does not make this count fractional.

This applies also to the two restriction types not bounded by the saturated
conductors: their all-order moment atoms were exhaustively classified by the
finite trace box and its zero tail. It does not justify integrality of the
extra endpoint-mixture variables or of any auxiliary variables whose meaning
has been relaxed. Only the670 oriented phase-atom variables are constrained
to be integers in this follow-up.

A floating-point mixed-integer solver is used only to find candidates. Any
feasible candidate is replayed after fixing its proposed integer phase counts
and checking a rational solution of the remaining auxiliary equations. A
reported numerical infeasibility is not an exclusion without an independently
checkable exact certificate. Unknown/time-limited outcomes likewise prove
nothing about existence.

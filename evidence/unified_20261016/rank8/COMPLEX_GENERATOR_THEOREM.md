# Complex 2D2 generator normal form

Let the graph have edges 01,12,23,24,35,45,56,67 and even vertices 0,2,5,7. Put z=sqrt(5), delta=sqrt(3+z), d=2+z, and phi=(1+z)/2. Its Perron-Frobenius weights are

    mu=(1,delta,d,delta*phi,delta*phi,d,delta,1).

For rectangular lopsided coordinates use the parity-rescaled weights

    w=(1,1,d,phi,phi,d,1,1).

For a loop l=(v0,...,v5), the associated matrix entry is indexed by paths (v0,v1,v2,v3) and (v0,v5,v4,v3). In these coordinates multiplication is ordinary block matrix multiplication. Rectangular caps are the unweighted sums over the inserted backtracking vertex. Rotation by two positions is encoded by

    T(v4,v5,v0,v1,v2,v3)
       = w(v0) w(v5) / (w(v2) w(v1)) * T(v0,v1,v2,v3,v4,v5).

These formulas fix all conventions; they are independently checked against the Temperley-Lieb idempotents below.

The 152 loop coordinates satisfying caps and rotation 1 form an eight-dimensional vector space. Choose coordinates at these loops:

| coordinate | loop |
|---|---|
| x0 | 012321 |
| x1 | 212323 |
| x2 | 212354 |
| x3 | 212453 |
| x4 | 232323 |
| x5 | 232354 |
| x6 | 232453 |
| x7 | 235453 |

For each path block, let E_i have matrix entries

    E_i[p,q] = w(p_i) / sum_{v~p_(i-1)} w(v)

when p and q agree away from i and p_(i-1)=p_(i+1), and zero otherwise. For i=1,2 these are the two normalized Temperley-Lieb idempotents. They satisfy E_i²=E_i and E1 E2 E1=E1/delta², E2 E1 E2=E2/delta². Thus

    f3 = I - delta²/d*(E1+E2) + delta²/d*(E1E2+E2E1).

The ideal of all equations T²=f3, in the eight-dimensional linear space, is **exactly** the ideal generated by

    x0+(3+z)x7/2,
    x1+(3-z)x7/2,
    x2+2x5,
    x3+2x6,
    x4+(z-1)x7/2,
    x5*x6-(5z-11)/2,
    x7²-(7-3z)/2.

This is an equality of ideals over Q(sqrt(5)), not only an equality of real, self-adjoint, numerical, or generic solution sets. In particular it also covers all complex specializations and contains no division by an unknown parameter during elimination.

Put k=(3-z)/2 and c=(5z-11)/2. Both are positive and nonzero. Every complex solution is specified by epsilon in {+1,-1} and lambda in C^x:

    x7=epsilon*k,
    x5=epsilon*sqrt(c)*lambda,
    x6=epsilon*sqrt(c)/lambda,

with the other five coordinates given by the displayed linear equations. Hence there are exactly two copies of C^x. The edge character that multiplies the directed edge 3->5 by lambda and its reverse by lambda^-1 has coordinate winding exponents

    (0,0,1,-1,0,1,-1,0).

It identifies all lambda values in each sign family. The signs generate the same planar subalgebra. The base at lambda=1 is self-adjoint in spherical coordinates: in each path block its rectangular matrix T obeys T H=H T^t, where H[p,p]=w(p1)w(p2). Therefore H^-1/2 T H^1/2 is real symmetric.

    python verify_gpa_certificate.py
    python -O verify_gpa_certificate.py

It contains rational-pair coefficients a+b sqrt(5), the 152-by-8 linear basis, the 82 distinct normalized square equations, seven normal-form equations, and explicit polynomial combination certificates.

The verifier uses only Python's standard library and exact fractions. It reconstructs all loops and cap/rotation equations, proves rank 144, verifies the eight normalized coordinate vectors, reconstructs every path block and f3, matches every stored equation to the resulting square equations, verifies every square equation modulo the normal form, and verifies each normal-form generator as an explicit degree-at-most-three combination of square equations. No Mathematica notebook, symbolic solver, floating-point tolerance, self-adjointness equation, or numerical certificate is needed to replay this result. The symbolic discovery scripts are separate research files and are unnecessary for verification.

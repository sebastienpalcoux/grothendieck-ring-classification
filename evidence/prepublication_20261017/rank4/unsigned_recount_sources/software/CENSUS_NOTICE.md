The independent tensor checker checks full fusion-ring axioms and all unit-fixing basis permutations; it is separate from the integer-elimination enumerator.

The OpenMP enumerator enumerate_census_parallel.cpp derives from code/rank4_census.cpp at the same commit. Its only additional search reductions are necessary interval bounds for the reconstruction identities a e + b h + c i = H0, a d + b g + c h = G0, a f + b i + c j = J0, and C a + A i = -B0. Since a,g,j lie in [0,M] and h,i lie in [b,M], failing these bounds makes a tuple impossible; no valid class is removed. The original serial implementation is retained as enumerate_census.cpp.

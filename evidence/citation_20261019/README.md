# Extended Haagerup citation replay inputs

The current publication cites both the Acta Mathematica construction and
*The Extended Haagerup fusion categories* in Annales Scientifiques de
l’École Normale Supérieure.

This additive archive retains the exact seven catalog/source files from commit
`4487d2bfd643ebe80a1199b31f3d2bdd1bc64983` needed by the existing rank-six
checksums and rank-seven historical source manifests. The ZIP contains only
those original bytes. Its inventory, sizes and SHA-256 hashes are listed in
`replay_files.json`; both the manifest and ZIP hashes are pinned in
`tools/current_publication.py`.

The historical verification dispatcher restores these files only into its
isolated replay directory, alongside the existing publication replay archive.
Current catalog files retain the full bibliography. Existing evidence archives,
certificate commitments and mathematical results are unchanged.

# Census and literature sources

The classification uses the rank-six tensor file from the exact repository
revision and SHA-256 hashes recorded in `repository_source.json`.
The repository supplies census completeness and uniqueness; the paper checks
its source correspondence and the categorification certificates.

`census_LICENSE.txt` reproduces the repository notice, whose stated scope is
new code in that repository. It does not assign a new license to this paper.

The Ng–Rowell–Wen rank-six ancillary tensors and their exact download URL and
hash are recorded in `research/m8_frontier/nrw_rank6_scan.json`. The manuscript
bibliography and model catalogue give attribution for categorical inputs.

`REVISION_NOTES_first_continuation.md` preserves the earlier seven-exclusion
release. Its unresolved statuses are historical. The root revision notes and
decision ledger describe the current second continuation. The full-tensor
import audit for the standalone R3582 and B13 arguments is retained in
`research/round2_external/IMPORT_AUDIT.md`; B13 lies outside this census.

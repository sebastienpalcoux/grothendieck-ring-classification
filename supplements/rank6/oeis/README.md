# Rank-six fusion-ring counts

The nine exact-multiplicity terms are **39, 154, 384, 872, 1582, 2768, 3814, 6999, 8809**; their sum is **25,421**. The OEIS offset is `1,1`.

These count all based fusion rings, regardless of categorifiability. Rank includes the unit; multiplicity is the maximum structure constant, including unit coefficients. All duality types and noncommutative cases are included.

The counting source is [Fusion Ring Census at revision 2a340871242879665fa7ba2b01fa15b8bdeaada3](https://github.com/sebastienpalcoux/fusion-ring-census/tree/2a340871242879665fa7ba2b01fa15b8bdeaada3). Its enumeration and coverage evidence are distinct from the classification package's import checks.

- `counts.csv`: exact and cumulative counts.
- `bfile_rank6_unassigned.txt`: exact terms in b-file format.
- `proposal.txt`: copy-paste sequence fields and source links.

No accession is presumed and no online submission has been made. Unresolved categorification questions do not affect these census counts.

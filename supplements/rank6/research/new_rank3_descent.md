# Rank-three near-group descent

## Theoretical statement and proof

If a based fusion ring contains basis elements 1, g, x with

g^2 = 1, gx = xg = x, x^2 = 1 + g + m x,

and m > 2, it has no categorification by a complex fusion category.
Indeed, the full additive subcategory generated by these three simple
objects is closed under tensor products and duals, so it is a fusion
subcategory with Grothendieck ring K(1,0,m,0). This contradicts
Ostrik, *Pivotal fusion categories of rank 3*, Theorem 4.1,
https://arxiv.org/pdf/1309.4822 (arXiv v1, printed p.13).
The cited theorem explicitly assumes only that K(1,0,m,0) is
categorifiable. Its proof reduces near-group categorifications to
pseudo-unitary ones up to Galois conjugacy; no pivotality assumption
on the ambient or subcategory is added here.

## New residual determination

R6_4_162 has g = b_3, x = b_4 and m = 4. The ordered basis (0,3,4)
gives precisely the displayed multiplication. The alternate x = b_5
also gives such a subring. Thus R6_4_162 is excluded in general.

## Exact automation

`software/new_rank3_subring.py` discovers such a triple from the tensor.
Its verifier independently checks all nine ordered products, including
every coefficient outside the three-element subring. It uses explicit
`exact.require` checks, which remain active under Python optimization.

Run:

    python software/new_rank3_subring.py
    python software/new_rank3_subring.py --verify
    python -O software/new_rank3_subring.py --verify

The all-census pass checks 16,612 tensors and yields 257 certificates,
including one previously unresolved record, R6_4_162. All 54 currently
allocated positive models are preserved. Independent rank-three m=0,1,2
controls are preserved. Optimized-mode tampering checks reject a changed
parameter, changed subring labels, changed scope, and changed source.

The standalone certificate collection is
`certificates/new_rank3_subring.json`. This is a newly applied published
necessary criterion; it is not advertised as a new mathematical theorem.

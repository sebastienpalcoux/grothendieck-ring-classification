# Source provenance

The MIT source notice and license inherited from the general package are retained
in `CENSUS_LICENSE`. The standalone unsigned enumeration and checking programs
used by this release are in `../../census/`; they are adapted from the user-supplied
pivotal package with general-case defaults and guards (M=31, D<1000). They do not
read that package or an external repository. `census_data.py` provides only exact
tensor expansion for the general signed cover. No missing historical bound-128
parameter file is a dependency of the delivered classification.

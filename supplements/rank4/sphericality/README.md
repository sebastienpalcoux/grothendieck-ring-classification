# Rank-four verification

Run the following command from this directory using Python 3.10 or later, SymPy (tested with 1.14.0), and g++ with C++17 support.

```sh
python3 verify.py --manuscript ../../../manuscripts/rank4.tex
```

The manuscript option additionally compares the fifteen printed table rows to their checked model data. For a replay from the verification directory by itself, use `python3 verify.py`.

## What each calculation verifies

* **Ordinary census.** The C++ enumerator solves three bounded linear equations and tests the remaining associativity relations. It generates the multiplication tables in the window of multiplicity at most 31 and global Frobenius–Perron dimension below 1000. Python regenerates this census in a temporary directory, compares exact records, verifies the tensor axioms and all unit-fixing permutations, and checks the integer leading minors that enforce the strict dimension bound. There are 1,642 self-dual tables and 50 with a dual pair.
* **Coverage checks.** Removing the two dimension-pruning steps gives 16,065 ordinary tables. An independent determinant expansion cuts this set back to the same 1,692 inputs. A direct matrix-commutation check on the 59,778 unsigned parameter assignments of multiplicity at most two yields the same 27 classes as the enumerator. The former comparison shares the bounded linear search, the latter shares the tensor presentations and canonicalization.
* **Finite descent.** `verify_descent.py` starts from the ordinary census, applies the structural and arithmetic tests proved in the paper, and checks all bounded local signed lifts needed by the descent.
* **Analytic estimates.** The programs `audit/verify_quadratic_intervals.py` and `quartic_bounds.py` reconstruct the finite rational and polynomial checks used in the quadratic and quartic bounds.
* **Models.** The reference tensors, simple positive dimensions, and model table are in `supplementary/models/`. All fifteen tensors are independently reconstructed from their group, product, quantum-group, near-group or exceptional fusion rules. Each matches one ordinary input. The character equations, dimensions, multiplicities and table entries are checked exactly. The references in the manuscript supply the existence of the categories and the classification in the pivotal case.

The reports in `results/` are regenerated by the command above. The input tensors and their mathematical parameters are in `supplementary/census/data/`.

## Origins of the code and data

The base tensor data, tensor utilities and independent model reconstructions are adapted from the rank-four verification sources delivered with the original manuscript. The earlier ordinary enumeration derives from the pivotal work of Jingcheng Dong, Sébastien Palcoux and Arnaud Plessis. The present package replaces its case-by-case elimination by a direct bounded linear search and adds the local descent, its analytic checks, the direct model-to-census comparison and a unified replay.
